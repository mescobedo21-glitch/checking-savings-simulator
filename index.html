Part 3 — ANALYZE: Joshua's Day

30 pts

Joshua starts with $116 checking and $200 linked savings.

Option #1: No Coverage

Transactions decline if funds are insufficient. Declined checks/eChecks/ACH receive a $35 NSF fee.

Option #2: Overdraft Coverage

All transactions accepted. $35 for each transaction exceeding available balance, maximum 3 fees/day.

Option #3: Overdraft Protection

All transactions accepted. $50 transfers from linked savings as needed; $10 fee per transfer.
